# API-контракт

Базовый префикс за nginx: `/api`

## Эндпоинты
| Метод | Путь | Описание | Успех | Ошибки |
|---|---|---|---|---|
| GET | `/projects` | Получить список проектов | 200 | - |
| POST | `/projects` | Создать проект | 201 | 400 ошибка валидации |
| DELETE | `/projects/:id` | Удалить проект по UUID | 204 | 400 неверный UUID или системный проект, 404 не найден |
| GET | `/tasks` | Получить список задач | 200 | - |
| POST | `/tasks` | Создать задачу | 201 | 400 ошибка валидации |
| PATCH | `/tasks/:id/status` | Переключить статус задачи | 200 | 400 неверный UUID, 404 не найден |
| DELETE | `/tasks/:id` | Удалить задачу по UUID | 204 | 400 неверный UUID, 404 не найден |

## Примеры payload

### Создание проекта
Запрос:
```json
{
  "name": "Мой проект"
}
```

Ответ `201`:
```json
{
  "id": "2ce5a4f0-09d9-46ad-9ac3-81f574799b41",
  "name": "Мой проект",
  "createdAt": "2026-03-01T12:00:00.000Z",
  "projectListType": "custom"
}
```

### Создание задачи
Запрос:
```json
{
  "title": "Оплатить счета",
  "projectId": "2ce5a4f0-09d9-46ad-9ac3-81f574799b41"
}
```

Ответ `201`:
```json
{
  "id": "4b9f6f94-5c9e-4284-99fe-e8ba8cc7a0cb",
  "title": "Оплатить счета",
  "status": "new",
  "createdAt": "2026-03-01T12:05:00.000Z",
  "projectId": "2ce5a4f0-09d9-46ad-9ac3-81f574799b41",
  "isTaskEdit": false
}
```

## Формат ошибок
Используется стандартный формат HTTP-исключений Nest, пример `404`:
```json
{
  "statusCode": 404,
  "message": "Project not found",
  "error": "Not Found"
}
```

Для ошибок валидации (`400`) ответ содержит сообщения `ValidationPipe`.
